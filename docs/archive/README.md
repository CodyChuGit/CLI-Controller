# Archive

Historical design notes, audit reports, and planning docs from the June 2026
production-hardening and pillars-rewrite passes. They lived on the
`audit/production-hardening` and `pillars/production-rewrite` branches, which
have been deleted — this directory is where that work is preserved.

**These describe the app as it was, not as it is.** They are kept for context
on why subsystems look the way they do. For current documentation start at
[../INDEX.md](../INDEX.md).

Product names were updated to "CLI Controller" in place; otherwise the content
is unchanged from the branch tips.
